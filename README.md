# Loop Sort — Game Analysis

Báo cáo phân tích Loop Sort 4.12.0, package `com.Garawell.LoopSort`, Unity 6000.0.77f1.

Ngày cập nhật: 25/11/2026.

Mở `index.html` để đọc báo cáo local hoặc truy cập GitHub Pages của repository.

13 tab: tổng quan, level, vật thể/cơ chế, boosters, kinh tế/quảng cáo, events, Daily, leaderboard/bot, IAP, analytics, khu vực/tiến trình, cấu hình và nguồn.

Trình xem 3D dùng mesh và texture trích từ game, camera orthographic theo prefab gốc, bố cục màn hình dọc. Có 1.299 dòng level ở mỗi bộ chính và 30 màn Daily. Bảng IAP đối chiếu 44 SKU. Thư mục Data/Evidence và các script cung cấp dữ liệu để kiểm tra lại.

Đây là báo cáo và bản tái dựng tĩnh, không phải game chơi được. Shader, animation và một phần setup module được chuyển đổi hoặc tái dựng trên WebGL. Cấu hình server, giá cửa hàng và dữ liệu live chưa được xác nhận trực tiếp. Xem phần giới hạn ở từng tab và từng level.

Three.js đi kèm giấy phép tại `vendor/three-LICENSE.txt`. Model, hình ảnh và nội dung game thuộc chủ sở hữu tương ứng.
